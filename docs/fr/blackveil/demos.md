# Démos sonores

Des presets d'usine à 140 BPM. Chaque démo joue **deux mesures du kick seul**, puis **le rumble
entre à la mesure 3** pendant quatre mesures, et le dernier kick résonne jusqu'au bout. Le kick est
le Kick 01 G intégré ; les presets sont tels quels, sortis directement de Blackveil, sans mixage ni
mastering.

Vous les trouvez dans le navigateur de presets, sous la même catégorie et le même nom.
