# Automation

Chaque contrôle visible est un paramètre hôte : vous pouvez l'automatiser ou l'assigner à un
contrôleur. Votre DAW les liste sous ces noms (en anglais, comme dans le plugin) :

| Section | Paramètres |
|---|---|
| Configuration | Source, Kick Trigger, Kick Division, Key |
| Source | Tune, Decay, Pitch, Pitch Decay, Drive, Level |
| Filter | Filter On, Filter Type, Filter Cutoff, Filter Resonance, Filter Env, Filter Env Decay |
| Dist | Dist On, Dist Mode, Dist Drive, Dist Tone, Dist Mix, Dist Crush |
| Delay | Delay On, Delay Time, Delay Ping-Pong, Delay Feedback, Delay Low Cut, Delay High Cut, Delay Mix, Delay Swing |
| Reverb | Reverb On, Reverb Type, Reverb Size, Reverb Damp, Reverb Width, Reverb Mix |
| EQ | EQ On, EQ Type, EQ Freq, EQ Gain, EQ Width, EQ Sub Cut |
| Grain | Grain On, Grain Mode, Grain Size, Grain Density, Grain Spray, Grain Mix |
| Duck | Duck Trigger, Duck Division, Duck Target, Duck Depth, Duck Low End |
| Output | Polarity, Phase, Width, Volume |
| Limiter | Limiter On, Limiter Drive, Limiter Ceiling, Limiter Release |
| Pied de fenêtre | Kick Level, Kick On, Rumble Level, Rumble Mute, Send Gate, Noise, Noise Color |

Non automatisables : la courbe de ducking, l'ordre de la chaîne d'effets, le kick choisi et la taille
de la fenêtre.

L'automation reste connectée d'une mise à jour de Blackveil à l'autre : les nouvelles versions ne
font qu'ajouter des paramètres.
